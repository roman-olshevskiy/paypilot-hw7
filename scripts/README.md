# Скрипти ДЗ7

Готові README, звіт, порожній шаблон і billing-reconciliation.json підтримуються без генераторів, які перезаписують фінальний текст. П’ять одноразових авторських скриптів видалено; їхні попередні версії залишаються в Git-історії.

- `analyze_hw7.py`, `plot_tokens.py` — перерахунок аналізу/графіка зі збережених captures; без генерацій. Аналіз перезаписує похідний analysis.json і копію b4.json.
- `verify_replay.py` — нативний CLI на записаних fixtures у чистому Git-клоні; без мережі й модельних викликів.
- `hw7_capture.py`, `docker_capture_entry.py`, `verify_docker_clone.py` — живі платні запуски й збереження доказів; потрібен явний HW7_PAID=1.
- `run_remaining.py`, `finish_series.py`, `run_nosummary_control.py` — оркестрація первинної кампанії, не команда повторного запуску готового ДЗ. Перші два змінюють калібрування/історичні знімки й створюють коміт; для нового запуску використовувати команди README в окремому робочому каталозі.
- `langfuse_export.py` — експорт спостережень локального Langfuse.

Живий повтор потребує окремої серії та нового обліку витрат; він не замінює історичні докази прийнятим результатом.
