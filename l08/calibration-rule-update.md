# Уточнення правила до калібрування

Початковий прогноз4c20fbb лишається незмінним. Пілот B2 показав input ratio1.09, тому15% запас може пропускати D15. До першого запуску власних кейсів і до читання їхніх defect даних змінено правило лише для BUD-D15: clean median tokens +5%; для інших +15%, latency +100% як планувалось. Це нове обґрунтоване рішення після пілота, не ретроспективна підгонка до фінальних дефектів. Фінальний clean також окремий від calibration, тож ризик хибного спрацювання перевіряється незалежно.
